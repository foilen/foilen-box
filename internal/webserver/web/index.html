Discovery

Server mode also stores and serves DHT records for other peers on the public network, which helps overall network health at the cost of some extra bandwidth and storage. Client mode only looks up records for yourself.

Known peers not seen (and currently disconnected) for this many days are automatically removed. 0 uses the default (14 days); -1 disables this and keeps peers forever.

NAT traversal

UPnP/NAT-PMP port mapping and NAT hole punching are always on, so peers behind a NAT can usually still connect directly.

Lets other group members connected to this peer be reached through it when they're otherwise unreachable. Only useful if this peer is itself publicly reachable (e.g. a VPS); costs it some bandwidth on their behalf.

TCP/UDP

Currently bound to port (none), used for both TCP and UDP (QUIC). "Default" lets the app pick a free port automatically and keeps using it across restarts; switch to "Specific" to pin a fixed port yourself, e.g. for firewall rules. Changing these settings restarts Realm's networking.

Web listener

Runs a standalone HTTP(S) server with a /p2p WebSocket bridge into this peer's normal libp2p port, so it stays dialable through firewalls/proxies that only allow common web ports out. Only useful for a peer with a stable public hostname/IP (e.g. a VPS); binding a port below 1024 needs OS permission the app may not have. Changing these settings restarts Realm's networking.

With "https", the certificate is self-signed and not meant to be trusted on its own: peers accept it because the real authentication happens afterwards, via Realm's own peer-identity handshake. Use "http" only when a reverse proxy in front of this peer already terminates TLS.

The announce hostname/port/protocol is what other peers are told to dial; it's needed since this address can't be auto-discovered. If left blank, this host's outbound IP is used instead of a hostname. Set announce port/protocol when a reverse proxy exposes a different public port (typically 443/https) than the port this process actually binds locally.
