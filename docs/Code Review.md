# Rules

- Methods must be sorted:
  - Can be alphabetically sorted
  - Can be sorted by functionality
  - Always continue what the current class does
- Ensure there is no typo in comments, methods names, variables, log messages, etc.
- There must not be more than 1 empty line separation.
- There must not be more than 1 space separation in a sentence.
- When a logic is common in different places, ensure no step is missing and the same pattern is reused. Also put common code in a method to reuse it.
- Ensure there is no dangling `TODO`
- Ensure there is no `Task*.md` file left
- Ensure the commit message doesn't have `WIP` in it
